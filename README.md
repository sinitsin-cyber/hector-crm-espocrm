# EspoCRM на своём компьютере

Запуск, остановка и предупреждения о данных — в шапке `docker-compose.yml`.
CRM: http://localhost:8080

## Шахматка объектов

Два вида сетки, CRM выбирает сама:

- **Многоквартирный дом** (у объектов заполнен подъезд): блок на каждый подъезд,
  строки — этажи, в клетке номер квартиры, комнатность, площадь, цена в млн.
- **Посёлок** (подъезда нет): одна сетка «ряд × номер»; сверху и справа — пустые места
  под новые дома.

Цвет клетки — статус: свободно (зелёный), бронь (жёлтый), продан (красный),
строится, сдан, не продаётся.

- Где: в карточке проекта (панель «Шахматка»), в меню «Объекты → Шахматка»
  и кнопкой в списке объектов.
- **Создать квартиры** (кнопка на карточке проекта): заполни «Подъездов», «Этажей»,
  «Квартир на этаже», сохрани и нажми. Квартиры «Кв. 1…N» создаются со сквозной
  нумерацией по подъездам. Повторное нажатие создаёт только недостающие.
  Комнатность, площадь и цену потом удобно проставить массово: список объектов →
  фильтр по проекту и «Номер в ряду» → отметить → «Массовое обновление».
- Клик по квартире — карточка, её можно сразу править. Клик по пустой клетке («+») —
  новый объект на этом месте.
- Над сеткой: счётчики по статусам (клик приглушает статус), итоги «продано на /
  в продаже на» и фильтр по комнатности.
- Красная пунктирная рамка — в одной клетке два объекта.

Что добавлено в CRM:

| Сущность | Поля |
|---|---|
| Проект (`CHousingProject`) | название, адрес, подъездов, этажей, квартир на этаже, описание, список объектов |
| Объект (`CProperty`) | название, проект, тип, статус, подъезд, комнатность, ряд/этаж, номер в ряду, площадь дома, площадь участка, цена, бронь до, покупатель, сделка |

Статусы «Продан», «Строится», «Сдан» идут в сумму «продано», «Свободно» и «Бронь» —
в «в продаже». В карточках контакта и сделки есть панель «Объекты».

## Где лежит код и как выложить правки

```
espo/custom/Espo/Custom/   сущности, поля, переводы, раскладки (сервер)
espo/client/custom/src/    страница шахматки и кнопки (браузер)
deploy.ps1                 копирует espo/ в контейнер, пересобирает и чистит кеш
```

Править файлы в `espo/`, потом `.\deploy.ps1` и Ctrl+F5 в браузере.

Если поля менять мышкой в «Администрирование → Менеджер сущностей», CRM пишет
изменения только в контейнер. Чтобы они не потерялись при следующем `deploy.ps1`,
забрать их в репозиторий:

```
docker cp espocrm:/var/www/html/custom/Espo/Custom espo/custom/Espo/
```

## Настройки, сделанные через интерфейс (в репозитории их нет)

Язык — русский, часовой пояс — Москва, валюта — рубли (формат «4 910 000 ₽», без копеек),
формат даты ДД.ММ.ГГГГ,
в меню группа «Объекты»: Проекты, Объекты, Шахматка.

## Запуск

1. Скопируйте `.env.example` в `.env` и задайте свои пароли.
2. Выполните `docker compose up -d`.
3. Откройте http://localhost:8080, логин `admin`, пароль из `.env`.
4. Выложите доработки шахматки: `.\deploy.ps1`.

Домашнее задание недели 5 курса: CRM развёрнута через Claude Code по `docker-compose.yml` из урока 5.2
и доработана под объекты недвижимости. Пароли вынесены из файла в `.env`, поэтому репозиторий открыт.
